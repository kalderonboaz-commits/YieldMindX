STAGE 2 RUN B -- SHRUNK SCORE_2 IMPLEMENTATION & EVALUATION
==================================================================
Implements exactly the audit's recommendation: cell-count-weighted
shrinkage added to score_2 (mirroring fit_additive_joint's shrink_joint
mechanism, shrink_k=8.0). score_1 untouched. Frozen validator (single/
2way/3way confirmatory logic, FDR, permutation, thresholds) untouched.
Ground truth was not consulted until all generic checks below passed.

------------------------------------------------------------------
1. WHAT CHANGED
------------------------------------------------------------------
New function compute_nonadditivity_screen_shrunk() added to
stage2_relval_common.py (fresh reimplementation, NOT an edit to the
shared/reused stage2_v3_common.py -- v3/v4/v5's frozen outputs remain
exactly reproducible). Each cell's (JOINT-ADDITIVE) departure is now
multiplied by count/(count+8.0) before squaring -- sparse cells shrink
toward "no departure," well-populated cells are barely affected.
Wired into stage2_relval_pair_screen.py's single score_2 computation
call, so channels B/C/G/H (all consumers of score_2) automatically use
the improved score. No other file touched.

------------------------------------------------------------------
2. GROUND-TRUTH-FREE SCORE QUALITY: BEFORE vs. AFTER
------------------------------------------------------------------
Correctness sanity: shrunk score <= raw score for every pair (guaranteed
algebraically); correlation between raw and shrunk across all 986,310
pairs = 0.995 (a refinement, not a wholesale change). Computation cost
unchanged (~1.2s, fully vectorized).

Correlation with the validator's OWN confirmatory delta_R^2 (computed on
the 11,881 pairs already tested under the pre-change candidate pool --
an internal-consistency check using already-frozen evidence, not planted
answers):
                    Pearson    Spearman
  raw score_2:       0.748      0.751
  shrunk score_2:    0.763      0.770
Modest, consistent improvement in both directions -- the shrunk score is
a measurably better proxy for what the confirmatory test actually finds.

Negative control for the new score alone (one group-block shuffle):
real top-2,000 cutoff = 0.620; shuffled max = 0.187; 0 shuffled pairs
exceed the real cutoff. Clean separation, consistent with (slightly
tighter than) the original score_2's own negative control.
