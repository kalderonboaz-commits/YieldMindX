STAGE 2 RUN B v2 -- IMPROVED-COVERAGE RELATIONSHIP DISCOVERY SUMMARY
==================================================================

LightGBM only (same locked Run B model family as v1). No engineered
features. No ground-truth document read anywhere in this pipeline. See
stage2_runB_v2_coverage_summary.txt for exact coverage accounting at every
stage.

------------------------------------------------------------------
WHAT CHANGED FROM v1
------------------------------------------------------------------
v1's single-parameter and interaction analysis depended on features
already having meaningful LightGBM split importance to enter a ~154-
feature screening set or ~50-feature interaction candidate pool. v2
replaces this with methods that do not require LightGBM to have used the
feature at all:
  - Univariate screen: model-free quantile-binned shape classifier, run
    on ALL 1,405 numeric predictors (100% coverage, vs. 154 in v1).
  - Pairwise interaction screen: a fully vectorized broad score covering
    ALL 986,310 possible numeric pairs (100% coverage, vs. ~50-feature
    pool / ~1,225 pairs in v1), computed via one matrix multiplication in
    under 2 seconds, with expensive SHAP/H-statistic confirmation applied
    only to the top 200 candidates.
  - New: generic cross-stage relationship analysis (360 pairs, 100%
    coverage of column-naming-matched stage pairs) and a genuine 3-way
    interaction search (776 systematically-generated candidate triples),
    neither of which existed in v1.

------------------------------------------------------------------
COMPUTATIONAL LIMITATIONS
------------------------------------------------------------------
- The univariate shape classifier is a simple sign-pattern heuristic on
  quantile-binned means with a standard-error significance filter -- not a
  formal nonparametric regression or spline fit. It can still misclassify
  genuinely smooth or multi-modal curves.
- The pairwise broad-screen statistic (residual-vs-bin-index correlation)
  is a proxy for interaction potential, not a formal interaction test --
  it is explicitly a cheap FIRST-PASS filter, with the expensive stage
  providing the real confirmation.
- Stage B confirmation and the 3-way search only cover the union of
  features that survived the cheap screens (122 features for pairs, a
  systematically-generated 776-triple candidate list for 3-way) -- see
  coverage summary for the exact accounting of what was, and was not,
  tested at each stage.
- The 3-way factorial contrast uses a 2x2 median-split design (the
  simplest, most sample-efficient factorial structure at n~960 rows) --
  finer-grained 3-way process windows (e.g. a narrow joint sweet-spot
  rather than a clean high/low split) would not be well captured by this
  specific test.
- No formal multiple-testing correction (e.g. Benjamini-Hochberg FDR
  q-values) was computed across the many thousands of individual tests
  performed across all four discovery stages combined -- the STRONG/
  MODERATE/WEAK/INCONCLUSIVE fold-stability labels and the single-shuffle
  negative control are the false-discovery safeguards used here, not a
  formal FDR procedure.
