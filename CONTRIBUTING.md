# Contributing

Read [AGENTS.md](AGENTS.md), the [project index](project-managment/00_index.md), and the active sprint before changing the project.

Use [software structure](project-managment/07_software_structure.md), [deployment](project-managment/08_deployment.md), and [engineering workflow](project-managment/09_engineering_workflow.md) for implementation setup. Select the actual stack before adding commands or executable CI.

Keep PRs focused. Describe behavior, tests actually run, remaining gaps, configuration changes and migration/rollback implications. Preserve unrelated changes. Follow [.codex/agent-policy.md](.codex/agent-policy.md) for agent ownership and model routing.
